# Tilra

Рабочая первая версия приложения для взрослых: английский, турецкий, современная арабская фусха и отдельная карта будущего коранического направления. Русский интерфейс. Стартовый рынок — Казахстан.

**Это стартовая библиотека из 5 уроков, а не полный курс A1/A2.** Все учебные материалы — черновики, подготовленные с помощью ИИ; внешняя экспертная проверка не проводилась. Коранические тексты, записи, толкования и таджвид не опубликованы.

## Быстрый запуск

Требуется Node.js 20.19+ или 22.12+ и npm.

```bash
cd /workspace/sites/tilra
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173). Для локальной копии используйте свой путь к каталогу проекта.

```bash
npm test        # Проверка обучения, хранения и сценария в DOM
npm run build  # TypeScript и производственная сборка в dist/
```

`dist/` можно разместить на обычном статическом хостинге с HTTPS. Маршруты используют `#`, поэтому серверные правила перенаправления не нужны. Секреты, ключи и платные API отсутствуют. Основные зависимости: TypeScript, Vite, Zod (проверка структуры данных), Lucide (иконки); Vitest и jsdom — для тестов.

## Что попробовать

1. На главной выберите английский и откройте «Первое знакомство».
2. Прочитайте цель, объяснение и примеры. Перейдите к практике.
3. В одном из заданий ошибитесь: появятся правильный вариант и объяснение. Повторная отправка не создаёт второй ответ.
4. Выйдите на главную и вернитесь в урок: проверенные ответы и текущий шаг сохраняются. Можно обновить страницу. При переключении на другой урок прежний черновик сохраняется в `drafts`.
5. В аудиозадании нажмите «Прослушать». Если языкового голоса на устройстве нет, откройте текст. Ответ с текстом не засчитывается как самостоятельное понимание на слух.
6. В самостоятельном ответе сначала напишите собственный вариант, затем сравните с образцом. Устную практику можно выполнить вслух или записать себя. Ни текстовая, ни устная самопроверка не получает оценку качества от приложения.
7. Завершите урок: откройте результат, словарь и повторение. Ошибки доступны сразу, слова — на следующий день.
8. В настройках выгрузите JSON. Восстановление проверяет версию и структуру файла и спрашивает подтверждение замены текущих данных.
9. Переключитесь на турецкий и арабский. В арабском уроке проверьте направление письма, огласовки, соединения и встроенные кнопки букв.
10. Откройте «Язык Корана»: там только отдельные этапы и список недостающих источников, лицензий и экспертных проверок.

## Архитектура простыми словами

| Файл                               | Назначение                                                                                                  |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `src/content.ts`                   | Карты направлений, уроки, переводы, примеры, допустимые ответы и сведения о проверке. Интерфейса здесь нет. |
| `src/model.ts`                     | Типы и Zod-схемы уроков, предсказуемая проверка ответов.                                                    |
| `src/progress.ts`                  | Версионированный формат прогресса, сохранение, результаты и расписание повторений. Не зависит от DOM.       |
| `src/main.ts`                      | Представления экранов, маршруты и обработчики действий.                                                     |
| `src/i18n.ts`, `src/locales/ru.ts` | Русские строки интерфейса и функция выбора перевода.                                                        |
| `src/style.css`, `src/art.ts`      | Адаптивный интерфейс и собственная SVG-иллюстрация.                                                         |
| `src/bootstrap.ts`                 | Начальная загрузка и сообщение об ошибке загрузки приложения.                                               |
| `tests/learning.test.ts`           | Проверки контента, ответов, хранения, прогресса и повторения.                                               |
| `tests/flow.test.ts`               | Сквозной сценарий действий в jsdom, без настоящего браузера.                                                |

Для маленького бюджета сервер пока не нужен: все данные ученика остаются в `localStorage` этого браузера под ключом `tilra.progress.v1`. Они сохраняются после каждого проверенного задания. Непроверенный текст ответа и аудиозаписи не сохраняются. При запрете записи показывается ошибка и остаётся возможность выгрузить текущие данные. Повреждённое хранилище не перезаписывается автоматически. Импорт ограничен 5 МБ. Вкладки получают обновления через событие `storage`; строгой транзакционной синхронизации нескольких одновременно проходящих урок вкладок нет.

Для нескольких устройств следующим этапом понадобится аккаунт и база данных. Модель прогресса уже отделена от экранов: можно заменить слой хранения, сохранив содержание уроков и проверку ответов. До этого регулярно делайте резервную копию. Очистка данных браузера или другой адрес сайта создают отдельное хранилище.

## Как добавить материал

1. Добавьте урок в `src/content.ts` со стабильным уникальным `id`, `courseId`, целью, предварительными требованиями и понятным объяснением.
2. Укажите примеры, словарь и задания. Сейчас поддерживаются `choice`, `input`, `order`, `listen`, `free`, `speak`.
3. Для `input` явно перечислите допустимые варианты. Нормализация убирает лишние пробелы и обычную пунктуацию, учитывает регистр языка. Турецкие `ı` и `i` не смешиваются. В арабском допустимые варианты с огласовками и без них задаются явно.
4. Заполните `review.source`, `review.status` и `review.notes`. Статус `reviewed` требует имени проверяющего и даты; он означает реальную внешнюю проверку, а не успешную сборку. Интерфейс первой версии консервативно обозначает всю стартовую библиотеку как черновую.
5. Добавьте `id` урока в соответствующий раздел карты. Будущие разделы оставляйте с `planned: true`. Стабильные идентификаторы не переиспользуйте для иного содержания: они связаны с сохранёнными ответами.
6. Выполните `npm test` и `npm run build`, затем вручную пройдите новый урок. Успешные тесты не подтверждают лингвистическую корректность.

Модель уровня уже допускает A1 и A2. B1/B2 намеренно отсутствуют в интерфейсе и контенте; позже расширьте перечисление уровней в схеме и добавьте программу. Кораническое направление имеет собственные этапы и не относится к CEFR.

## Что означает прогресс

- Следующий урок открывается после минимум четырёх самостоятельных однозначных ответов с точностью не ниже 80%. Это технический порог первичной практики, а не доказательство освоения навыка.
- Процент курса и количество пройденных уроков относятся только к опубликованным стартовым урокам.
- В результатах навыки показывают число различных заданий, на которые был правильный самостоятельный ответ. Для подтверждения освоения нужны новые примеры и отсроченная проверка. Таких итоговых проверок пока нет, поэтому статус «уровень освоен» не присваивается.
- Свободные и устные ответы получают `correct: null`; ответы после открытия транскрипта имеют `assisted: true`. Они исключены из балла самостоятельной практики.
- После правильного повторения интервал растёт: 1, 3, 7, 14, 30 дней. После ошибки — 10 минут. Это прозрачный стартовый алгоритм, не адаптивная исследовательская модель памяти.
- Время в ежедневной цели оценочное: сумма запланированных длительностей завершённых уроков. Это не измеритель реального времени за экраном.

## Арабский, звук и источники

Арабский отображается с `lang="ar"`, `dir="rtl"` и `bdi`; Noto Naskh Arabic помогает читать огласовки. Русские части сохраняют LTR. Начальный урок вводит бa, та, алиф, фатху и формы соединений. Транслитерация ограничена первоначальным объяснением букв. Фусха не объявляется заменой местным разговорным диалектам.

Для упражнений современного языка доступен синтез речи устройства. Он явно помечен и зависит от установленных голосов. Для уроков Корана синтез не используется. Никакие аудиоданные на сервер Tilra не загружаются. Запись требует HTTPS/localhost, разрешения на микрофон и поддержки `MediaRecorder`; это необязательная личная запись без автоматической оценки. Системный сервис синтеза речи может зависеть от поставщика браузера или ОС.

Для публикации коранических материалов ещё нужны: проверенный источник текста и его версия; согласованный перевод; записи квалифицированного чтеца; понятные права на использование, хранение и распространение каждого вида материалов; арабист и специалист по соответствующей методике. Конкретные источники и лицензии пока не выбраны. До их согласования публикуется только структура раздела.

Английский и турецкий требуют редактора, проверки естественности, переводов и допустимых вариантов ответа. Весь арабский требует проверки арабистом, в особенности огласовки, соединения, формы обращения и последовательность ввода материала.

## Локализация

Основные ключи навигации — `messages.ru` в `src/i18n.ts`, остальные тексты — `src/locales/ru.ts` (ключи по исходному русскому тексту, как в gettext). Для казахского добавьте словарь `kk`, расширьте `Locale` и реестр словарей, сохраните выбор локали и добавьте вариант в настройках. Проверьте фразы с числами и порядок частей предложений; их следует объединять в параметризованные сообщения по мере перевода. Учебные объяснения и русские переводы находятся в контенте и требуют отдельной локализации; это не программные компоненты.

## Выполненные проверки и ограничения

Автоматически проверяются структуры всех уроков, допустимые ответы, специфические турецкие и арабские случаи, отсутствие фиктивной оценки речи, сохранение незавершённого урока, обработка повреждённых данных и переполнения хранилища, расписание повторений и полный сценарий в DOM. Проверены признаки RTL в разметке и клавиатура арабского ввода. Производственная сборка проверяет типы.

В этом окружении инструмент браузерного управления не предоставлен. Поэтому реальные размеры экрана, отсутствие горизонтального скролла на телефоне, фактическое начертание арабского шрифта, воспроизведение звука и запись микрофона **не проверены в настоящем браузере**. Адаптивные стили подготовлены для телефона и компьютера; перед публичным запуском проверьте Chrome/Safari на 360, 390, 768 и 1440 px, масштаб 200%, навигацию клавиатурой и экранный диктор. Внешние Google Fonts необязательны: при их недоступности используются системные шрифты.

## Следующие шаги по приоритету

1. Редакторская и арабистическая проверка всей стартовой библиотеки; исправление и атрибуция источников.
2. Проверка интерфейса на реальных телефонах и браузерах, доступности, голоса и микрофона.
3. Полная программа A1, затем A2: зависимости навыков, больше новых контекстов, отсроченные контрольные работы и реальные диалоги. Не объявлять уровень пройденным до этого.
4. Лицензированные человеческие записи для аудирования; педагогическая рубрика и реальные механизмы обратной связи по свободной речи.
5. Казахская локализация с языковым редактором.
6. Учётные записи и синхронизация при подтверждённой потребности; сначала выбрать бюджет и способ размещения. Платные сервисы сейчас не подключены.
7. Отдельная редакторская система версий контента, миграции прогресса при изменении заданий и журнал проверок.
